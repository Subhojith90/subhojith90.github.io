# Subhojit Halder — Personal Portfolio

The source for [subhojith90.github.io](https://subhojith90.github.io), built with Astro and deployed as a static GitHub Pages site.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

The production-ready static files are written to `dist/`.

## Content safety

This repository is public. Do not commit private documents, credentials, unpublished manuscripts, personal addresses, passport or visa information, or confidential employer material.
